Одна команда `python run_all.py` повторно генерирует данные, решает базовую задачу, проводит сценарии, независимую проверку, сохраняет CSV, графики и лог.

## Математическая модель
`x[i,j]` — объём груза, отправляемый со склада `i` в магазин `j`.

Минимизируется стоимость:
`min sum_i sum_j cost[i,j] * x[i,j]`

Баланс складов:
`sum_j x[i,j] = supply[i]` для каждого склада.

Удовлетворение спроса:
`sum_i x[i,j] = demand[j]` для каждого магазина.

Ограничения маршрутов:
`0 <= x[i,j] <= capacity[i,j]`.

Базовая задача сбалансирована: суммарный запас равен суммарному спросу. Перевозка по всем 24 прямым маршрутам разрешена; промежуточных хабов и потерь груза нет.

## Решатель и проверка
Используется SciPy `linprog` с HiGHS, метод dual simplex (`highs-ds`), `presolve=True`. После решения отдельная функция на NumPy проверяет балансы складов и магазинов, пропускные способности, неотрицательность и повторно вычисляет стоимость с допуском 1e-7.
